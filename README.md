# C-Programming-Journey
I am a BCA first-semester student learning C programming step by step.
This repository contains all the programs I write while learning.

## Topics Covered
- Week 1: Basics (variables, data types, input/output, operators)
- Week 2: Conditions (if-else, switch)
- Week 3: Loops (for, while, do-while)
- Week 4: Patterns and number problems

## How to run a program
gcc filename.c -o output
./output
